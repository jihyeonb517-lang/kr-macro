# 국장 매크로 대시보드 — 인수인계 문서

새 채팅에서 이어서 작업할 때 이 문서부터 읽으면 됩니다. (마지막 정리: 2026-10-28)

## 새 채팅 시작 방법

1. Claude 앱에서 이 폴더(`바탕화면\국장 매크로 대시보드`)를 열고 새 채팅을 시작합니다.
2. 첫 메시지로 이렇게 쓰면 됩니다.
   > README.md 읽고 국장 매크로 대시보드 이어서 작업해 주세요.

## 작업 원칙 (사용자와 정한 것)

- **답변은 항상 한국어로.**
- **ChatGPT와 협업하지 않음.** 지표 선택, 구간 기준, 문구는 Claude가 정하고 결과로만 보여 준다.
- **엑셀 출력 없음.** HTML 대시보드만 만든다.
- **다루는 기업은 삼성전자(005930)·SK하이닉스(000660) 두 곳뿐.** (코스피200·코스닥150 확장 계획은 취소)
- **색은 IV Terminal 팔레트**(`문서\Codex\퀀트\frontend\src\app\globals.css`)를 따른다. 참고 화면을 그대로 따라 하지 않는다.
- **API 키는 `kr_macro\.env`에만.** `indicators.json`이나 채팅에 넣지 않는다. 키 값을 화면에 출력하지 않는다.
- **IV Terminal(`문서\Codex\퀀트`)은 미국 주식 전용.** 한국 관련 기능은 이 대시보드에 넣는다.

## 실행

- `대시보드 열기.bat` 더블클릭 → 데이터 갱신(약 30초~1분) → 브라우저로 `kr_macro\output\dashboard.html` 열림
- 명령으로: `python kr_macro\build.py` (이 폴더에서)
- 확인만 할 때: `대시보드 열기.bat --no-open` (브라우저를 열지 않음)
- 필요한 것: Python, `pandas`, `yfinance`, `pykrx` (이 PC에 설치되어 있음). 차트는 인터넷에서 ECharts·TradingView Lightweight Charts를 불러오므로 볼 때 인터넷 필요.

## 데이터 출처와 키 (`.env` 항목)

| `.env` 키 | 쓰는 곳 | 상태 |
|---|---|---|
| `ECOS_API_KEY` | 경기선행지수 순환변동치(`901Y067`/`I16E`), 코스피 시가총액 일별(`802Y001`/`0183000`) | 입력됨 |
| `KRX_ID`, `KRX_PW` | pykrx 로그인: 외국인 순매수 비율, 코스닥 지수·시가총액, 종목 수급(투자자별·공매도) | 입력됨 |

## 주요 결정과 이유

### 매크로 탭 지표
- 구간 기준은 `indicators.json`의 `zones`. 2010년 이후 분포를 보고 정했다.
- **외국인 순매수 · 신용잔고 · 고객예탁금은 금액이 아니라 비율**로 본다. 시장 규모가 해마다 커져서 조원 금액은 시기 비교가 안 되기 때문.
  - 외국인: 20일 누적 순매수 ÷ 같은 기간 코스피 거래대금
  - 신용잔고: 코스피 신용거래융자 ÷ 코스피 시가총액
  - 고객예탁금: 투자자예탁금 ÷ 코스피 시가총액
- 시장 내부의 200일선·50일선 위 종목 비율은 코스피 대형주 약 100종목 표본(`breadth_universe`).
- **수출 증가율은 관세청 통관 수출 총계**(최근 3개월 합계 ÷ 1년 전 같은 3개월). 원계열이라 전년 같은 달끼리 비교해 계절성을 없앤다. OECD 계절조정치(FRED `XTEXVA01KRM667S`)와 상관 0.999로 같은 흐름이고 한 달 더 빠르다. 관세청 수신이 실패하면 OECD 값을 쓰고 카드에 그렇다고 표시한다. 구간(-5/3/15%)은 2005년 이후 관세청 기준으로 21·21·29·29%씩 나뉘어 그대로 둠 (`calc.src = customs_yoy3m`).

### 삼성전자·하이닉스 탭
- **TradingView 위젯은 KRX 종목을 막아 둠**(고급 차트·종목 개요·미니 차트 모두 "트레이딩뷰에서만 볼 수 있음"). 그래서 TradingView가 공개한 **Lightweight Charts 4.2.0** 엔진에 Yahoo 시세를 넣고, IV Terminal의 TradingView 카드 모양(툴바·OHLC 정보줄·기간 버튼·시계)을 따라 만들었다.
- 캔들만 사용(바·라인 삭제). 색은 TradingView 기본(상승 청록 `#26a69a`, 하락 빨강 `#ef5350`).
- **이동평균 5·20·60·120·240일**, 각각 켜기/끄기 가능.
- **피보나치 되돌림**: 0 = 최근 1년 최고가, 1 = `indicators.json`의 `fib_low`(삼성전자 189,200 / 하이닉스 1,171,000, 사용자가 지정). 박스는 고점 이전에 저가가 `fib_low`와 가장 가까웠던 날(삼성 3/25, 하이닉스 4/23)부터. 레벨 가격은 KRX 호가 단위로 맞춤. 켜기/끄기 버튼 하나.
- **투자자별 매매 동향**: 1·3·6개월, 전체/외국인/기관/개인, 누적/일별, 수량(주)/금액(억원) 버튼.
- **수급 표**: 기관·외국인·기관+외국인·개인의 5일/20일 순매수, 매집 지속성(20일 중 순매수 일수, 연속 일수), 공매도 비중(당일·5일 평균·5일 전 대비).
- 기업 지표 카드(시가총액·PER·PBR·배당·외국인 지분율·52주 범위)는 사용자 요청으로 삭제함.

### 수출 탭
- 반도체 = 집적회로(HS 8542) 전체. SSD는 관세청 분류상 저장매체(HS 8523)라 품목 카드에서 따로.
- 품목 HS 코드는 관세청 API가 돌려준 공식 품목명으로 확인함: DRAM `8542321010`(디램), MCP `8542323000`(복합구조칩), SSD `8523511000`, 낸드 `8542321030`(플래시 메모리), 프로세서·컨트롤러 `8542311000`, 메모리 MCO `8542324000`, 기타 집적회로 `854239`, 반도체 장비 `8486`.
- 관세청 API는 한 번에 12개월까지만 조회 가능. 품목코드 없이 월 단위로 요청하면 전체 총계가 나와서 한 달에 한 번 요청으로 총계와 품목을 함께 뽑는다.
- 저장본은 **2000-01부터**(`exports.first_month`, 매크로 탭 과거 분포용). 처음 받을 때 약 5분, 이후엔 최근 두 달만 다시 받는다. 2000년대 품목 열은 HSK 개정 전 코드라 0이거나 부정확할 수 있다(수출 탭은 최근 36개월만 쓰므로 영향 없음).

### 뉴스
- 주요 언론사는 **도메인으로** 판별(`news.py`의 `MAJOR_OUTLETS`). 주간지·전문 채널(주간동아 등)은 제외.
- 같은 내용 묶기: 회사명·[속보] 등을 뺀 제목 글자쌍 겹침이 묶음 평균 0.45 이상이면 같은 묶음(72시간 이내). "하나라도 비슷하면 합치기"는 실적 발표일에 24건이 한 묶음이 되는 문제가 있어 평균 방식으로 바꿨다.

## 아직 안 된 것 / 알려진 한계

- **수출 1~20일 잠정치**: 관세청이 API 없이 보도자료(PDF·한글)로만 발표 → 아직 미구현.
- **종목별 프로그램 매매(차익/비차익)**: pykrx에 없고 KRX 출처를 확정하지 못해 수급 표에서 뺐다.
- **뉴스 AI 요약**: 코드는 있음, `ANTHROPIC_API_KEY`를 넣으면 동작(6시간 캐시).
- 뉴스 묶기는 제목 문자 기준이라 표현이 완전히 다른 같은 사건은 따로 보일 수 있다.

## 관련 프로젝트

- **IV Terminal** (`문서\Codex\퀀트`): 미국 주식 분석 웹앱(FastAPI + Next.js). 이 대시보드와 코드·DB를 공유하지 않는다. 실행은 `start-local.cmd`.
